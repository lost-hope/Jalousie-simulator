Jalousie Simulator

ESP32-Firmware direkt im Browser installieren – kein Treiber, keine IDE nötig.

📦 Was ist das?

Der Jalousie Simulator ist ein ESP32-Projekt, das eine motorisierte Jalousie auf einem TFT-Display nachbildet. Zwei Taster ("Auf" / "Ab") steuern die Animation: Die Jalousie fährt herunter, die Lamellen schließen sich, und beim Hochfahren öffnen sie sich zuerst, bevor die Jalousie wieder hochfährt. Werden beide Taster gleichzeitig gedrückt, simuliert die Firmware einen Fehlerfall ("Kurzschluss") inklusive Warnton.

Gedacht ist das Projekt zum Testen von Steuerungslogik und Tasterverdrahtung, ohne dass ein echter Jalousie-Motor angeschlossen sein muss.

🔧 Hardware

  • ESP32 Dev Board
  • 2,4" TFT-Display, ILI9341-Controller, 240×320px, SPI
  • 2 Taster gegen Masse (intern Pullup, aktiv Low)
  • Optional: aktiver Buzzer für die Fehlertonfolge

⚡ Firmware installieren

Board per USB anschließen und installieren – läuft komplett im Browser über Web Serial.

Dein Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge auf dem Desktop verwenden. Web Serial ist nur über HTTPS verfügbar (localhost ausgenommen).
  1. ESP32 per USB-Kabel mit dem Computer verbinden
  2. "Jetzt installieren" klicken und den seriellen Port auswählen
  3. Warten, bis der Flash-Vorgang abgeschlossen ist – fertig

Funktioniert in Chrome oder Edge auf dem Desktop (Web Serial API). Auf dem Smartphone oder in anderen Browsern (z. B. Firefox, Safari) steht die Installation nicht zur Verfügung.

⏱️ Einstellungen

Fahrzeiten direkt auf dem Board anpassen – kein Neuflashen nötig.

Dein Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge auf dem Desktop verwenden.

Ungültige Werte (keine Zahl oder außerhalb des gültigen Bereichs) werden vom Board abgelehnt – der bisherige Wert bleibt dann unverändert.
